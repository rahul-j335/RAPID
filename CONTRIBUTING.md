# Contributing to RAPID

Thank you for your interest in contributing to **RAPID**! 🌊

## How to Contribute
1. **Fork or create a branch:** Always create a descriptive branch for your work (e.g. `feat/sensor-graph` or `fix/nav-link`).
2. **Make your changes:** Keep commits clean and write descriptive commit messages.
3. **Test locally:** Ensure the app runs without TypeScript or runtime errors using `npm run dev`.
4. **Submit a Pull Request:** Link any relevant issue using `Resolves #<issue_number>`.

## Pull Request Guidelines
- Follow existing code style and naming conventions.
- Keep PRs focused on a single change.
- Be respectful and constructive in review comments.
